# Company Logos

Place your company/brand logos here.

## Recommended specs
- **Format:** SVG preferred (scales perfectly). PNG also works.
- **Size:** 160 x 48 px (or any size keeping that ~3.3:1 aspect ratio)
- **Color:** White or light gray (#ebebeb) — monochrome works best on dark backgrounds
- **Background:** Transparent
- **Naming:** lowercase, hyphenated (e.g., `future-infinit.svg`, `malba.svg`)

## Current placeholders
The site will show text placeholders until you add the real logos here.
Update the logo list in `src/components/LogoCarousel.tsx` when adding logos.
